# Rust guidelines

Apply the relevant guidelines to the requested Rust work.

Read the applicable `AGENTS.md` instructions first. Repository instructions take
precedence over this skill and its reference; using the skill does not expand
scope, API permissions, or authorization to add tests or run checks.

Use [GUIDELINES.md](references/GUIDELINES.md) as the authoritative local copy.
Search its headings or guideline identifiers, then read only the sections relevant
to the current task rather than loading the entire reference by default.

Useful entry points include `M-CANONICAL-DOCS` for documentation,
`M-STRONG-TYPES` for API design, `M-ERRORS-CANONICAL-STRUCTS` for errors,
`M-UNSAFE` for unsafe code, and the performance and async sections for I/O work.
Read associated explanations and examples before applying a guideline.

Apply findings within the authorized task scope. Report relevant findings that
require changes outside that scope or additional public API authorization.
